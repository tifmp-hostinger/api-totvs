RM-API — painel de controle de rotas

Ative/desative qualquer rota da API em tempo real, acompanhe o uso (requisições, último status, duração) e execute chamadas de teste com a resposta formatada — tudo por esta interface.
Como funciona: a lista vem de GET /admin/rotas (exige a API key). O interruptor de cada rota grava o estado no servidor — rota desativada responde 503 imediatamente, sem tocar o RM. Rotas com 🔒 são protegidas (health check e o próprio painel) e não podem ser desligadas. Executar em rotas POST grava dados reais no RM — o painel pede confirmação.
