RM-API — referência de endpoints

Integração com o TOTVS RM via SOAP. Ajuste a URL base e os campos; cada endpoint gera o cURL pronto para copiar (no terminal ou no Import cURL do n8n). A página não executa requisições — apenas monta os comandos.
Base path na raiz: as rotas são /pessoas, /rm/test etc., sem /api. POST cria/altera dados reais no RM — cuidado ao testar gravações. Em POST, envie sempre Content-Type: application/json.
